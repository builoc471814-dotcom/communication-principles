# 提示词（v3）


```
你现在要操作豆包侧边栏浏览器里的超星答题页面（已经打开了），帮我自动做题并提交。
## 技术要求（v3 实测踩坑，必须遵守）
- 用 computer_use_tool 的 plane="bu"（侧边栏浏览器），代码里 import seed_browser_use as bu
- 全程用 bu.js() 执行 JavaScript 操作 DOM，不要截图、不要用坐标点击
- 视口宽度约1135px，高度667px
- 【关键】bu.js() 只支持同步 JS，禁止写 async/await、Promise、setTimeout 包裹的 IIFE
  （会报 RuntimeError: "GAC Server ... Promise was collected"；副作用可能已执行但不可靠）
- 【关键】所有等待/延时一律用 cell 里的 Python time.sleep()，不要在 JS 里等
- 【关键】点击选项 和 "确认选中+提交" 必须拆成两次独立 bu.js() 调用
  （Vue 是 next-tick 才把 is-checked 类刷到 DOM 上，同一轮 JS 里点完立刻读/提交会读到旧状态）
- 【关键】多选题 .el-checkbox 必须点它内部的原生 input：box.querySelector('input').click()
  外层 label.click() 实测不可靠（同一次点 A、C，C 中 A 失灵）；
  也不要手动 input.checked=true 再 dispatch change（原生框勾了，Vue 状态不认）
- 【关键】单选题/判断题 .el-radio 直接外层 radios[i].click() 即可，实测稳定

## 页面DOM结构（已探明，直接用）
- 题型标签：`.topicType`（文本为 单选题/多选题/判断题）
- 题干：`.dataCon .con > p`（innerText 即题干）
- 选项容器：
  - 多选题：`.el-checkbox`，内部 `<input type="checkbox" value="字母">`，点这个 input
  - 单选题/判断题：`.el-radio`，点外层 label（判断题选项文本为"对/错"）
- 提交按钮：`div.sendABtn`（点 offsetParent 非空的那个）
- 当前活动题：含可见 sendABtn 的 `.dataCon`；取不到就取最后一个 `.dataCon`
- 答案反馈：`.preAppendContentBox`（提交后显示"回答正确！"或错误说明）

## 片段1：快速读取题目（一次调用，同步，直接用）
(() => {
  const cards = [...document.querySelectorAll('.dataCon')];
  const active = cards.find(d => [...d.querySelectorAll('.sendABtn')].some(b => b.offsetParent !== null)) || cards[cards.length - 1];
  const con = active?.querySelector('.con');
  return JSON.stringify({
    type: active?.querySelector('.topicType')?.textContent.trim() || '',
    stem: con?.querySelector('p')?.innerText.trim() || '',
    opts: [...(con?.querySelectorAll('.el-checkbox, .el-radio') || [])]
      .filter(o => o.offsetParent !== null)
      .map(o => o.querySelector('.el-radio__label, .el-checkbox__label')?.textContent.trim())
  });
})()
返回 opts 为空 = 新题还在加载，不要停下汇报，静默轮询即可。

## 片段2：点击单选/判断选项（同步；把 LETTER 换成实际字母，判断题换"对"/"错"）
(() => {
  const cards = [...document.querySelectorAll('.dataCon')];
  const active = cards.find(d => [...d.querySelectorAll('.sendABtn')].some(b => b.offsetParent !== null)) || cards[cards.length - 1];
  const radios = [...(active?.querySelectorAll('.el-radio') || [])].filter(r => r.offsetParent !== null);
  const labels = radios.map(r => r.querySelector('.el-radio__label')?.textContent.trim() || '');
  const i = labels.findIndex(t => t.startsWith('LETTER') || t === '对' || t === '错');
  if (i < 0) return 'NOT_FOUND:' + JSON.stringify(labels);
  radios[i].click();
  return 'CLICKED:' + labels[i];
})()

## 片段3：点击多选题选项（同步；点原生 input。多个字母就把下面 push 进数组）
(() => {
  const WANT = ['LETTER1', 'LETTER2']; // 改成实际字母
  const cards = [...document.querySelectorAll('.dataCon')];
  const active = cards.find(d => [...d.querySelectorAll('.sendABtn')].some(b => b.offsetParent !== null)) || cards[cards.length - 1];
  const boxes = [...(active?.querySelectorAll('.el-checkbox') || [])].filter(b => b.offsetParent !== null);
  const labels = boxes.map(b => b.querySelector('.el-checkbox__label')?.textContent.trim() || '');
  const clicked = [];
  for (const w of WANT) {
    const i = labels.findIndex(t => t.startsWith(w));
    if (i < 0) { clicked.push(w + ':MISSING'); continue; }
    const input = boxes[i].querySelector('input');
    if (!boxes[i].classList.contains('is-checked')) input.click();
    clicked.push(labels[i].slice(0, 8));
  }
  return JSON.stringify(clicked);
})()

## 片段4：确认选中状态并提交（同步；必须在片段2/3之后，单独一次调用）
(() => {
  const cards = [...document.querySelectorAll('.dataCon')];
  const active = cards.find(d => [...d.querySelectorAll('.sendABtn')].some(b => b.offsetParent !== null)) || cards[cards.length - 1];
  const radios = [...(active?.querySelectorAll('.el-radio') || [])].filter(r => r.offsetParent !== null);
  const boxes = [...(active?.querySelectorAll('.el-checkbox') || [])].filter(b => b.offsetParent !== null);
  const checkedRadios = radios.filter(r => r.classList.contains('is-checked')).length;
  const checkedBoxes = boxes.filter(b => b.classList.contains('is-checked')).map(b => b.querySelector('.el-checkbox__label')?.textContent.trim().slice(0, 1));
  if (checkedRadios === 0 && checkedBoxes.length === 0) return 'NOTHING_SELECTED';
  const btn = [...document.querySelectorAll('div.sendABtn')].find(b => b.offsetParent !== null);
  if (!btn) return 'NO_SUBMIT_BTN';
  btn.click();
  return 'SUBMITTED:' + JSON.stringify(checkedBoxes);
})()
- 如果返回 NOTHING_SELECTED：说明刚才的点击没生效，回到片段2/3 重新点一次，再调片段4
- 如果片段3 报告某个字母 MISSING：检查字母是否写对（A/B/C/D…）

## 片段5：等下一题的 Python 轮询（在 bu 的 cell 里跑，不要用 JS sleep）
import seed_browser_use as bu, time
last_stem = "<上一题题干全文>"
for i in range(15):
    time.sleep(2.5)
    res = bu.js(/* 片段1 的 JS */)
    data = eval(res)
    if data.get('stem') and data['stem'] != last_stem and data.get('opts'):
        print('NEW:', res); break
else:
    print('TIMEOUT')

## 答题流程（循环执行，不要停，直到我说停）
1. 片段1 读题（题型、题干、选项）；opts 空就等 2.5s 重读，静默
2. 根据选项内容分析，确定正确答案（单选/判断 1 个字母或对/错；多选 1~N 个字母）
3. 片段2（单选/判断）或片段3（多选）点击对应选项
4. 单独一次调用跑片段4：确认选中且提交；NOTHING_SELECTED 就回第3步
5. 片段5 轮询下一题；拿到新题干（与上一题不同）就回到第1步
- 遇到"错后小问题"（答错后的巩固题）按同样流程做
- 题干与上一轮相同且没有新题：多等几秒再试，绝不重复点击或重复提交

## 注意事项
- 不截图、不汇报中间加载状态，静默循环作答直到用户喊停
- 如果 bu 会话断开（报 BU_NO_ACTIVE_PAGE、bu.list_tabs() 返回空）：
  用 bu.new_tab(答题页URL) 重新打开同一页面，页面会自动恢复进度，然后继续循环
- 坐标点击不靠谱，全程用 JS 操作 DOM
- 同一道题不要重复提交；提交前片段4 会先校验有没有选中
```

## v3 相比 v2 的关键升级
| 项目 | v2 | v3（实测修正） |
|------|----|----|
| 异步等待 | 提示"等2~3秒"，实际写法含糊 | 明确 bu.js 只支持同步 JS，等待一律用 Python time.sleep() 轮询，禁止 async/await |
| 多选点击 | "点 .el-checkbox 外层容器，延时200ms" | 实测外层 label 点击不可靠（C 中 A 失灵），改为点内部原生 input.click() |
| 状态同步 | 没提 Vue next-tick | 明确"点击"和"确认+提交"必须拆两次调用，否则读到旧状态 |
| 提交前校验 | 直接点 sendABtn | 片段4 先校验 is-checked/is-checked 至少有一项选中，避免空提交 |
| 多选补选 | 无 | 片段3 自动跳过已选中项；片段4 返回 NOTHING_SELECTED 时回到片段3 重点 |
| 片段化复用 | 一段长流程描述 | 拆成 读题/点单选/点多选/确认提交/轮询 5 段可直接复制的 JS，减少临场写错 |
| 会话恢复 | bu.new_tab 重连 | 同 v2，保留（本次实测有效） |
